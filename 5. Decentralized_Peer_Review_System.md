# Decentralized Peer Review System for Researchers

## Overview
The Decentralized Peer Review System is a blockchain-based platform aimed at creating a transparent, secure, and efficient peer review process for researchers. The system leverages the principles of decentralization, immutability, and cryptographic security to address the challenges of bias, inefficiency, and lack of transparency in traditional peer review processes.

---

## Features
- **Decentralized Platform:** Built on blockchain to ensure transparency and immutability.
- **Reviewer Anonymity:** Ensures unbiased reviews through pseudonymous identities.
- **Incentive Mechanism:** Rewards reviewers with tokens for high-quality reviews.
- **Smart Contracts:** Automates the review submission, evaluation, and reward distribution processes.
- **Secure Storage:** Utilizes IPFS for storing research papers and reviews securely.

---

## Tech Stack
- **Blockchain:** Ethereum (Solidity for Smart Contracts)
- **Frontend:** React.js
- **Backend:** Python (Flask/FastAPI)
- **Database:** PySQLite for off-chain storage
- **File Storage:** IPFS (InterPlanetary File System)
- **Authentication:** Metamask for wallet integration

## Installation
1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Cleven7/Decentralized-peer-review-system-for-researchers.git
   cd Decentralized-peer-review-system-for-researchers
   ```
2. **Install Dependencies:**
   - Backend:
     ```bash
     cd backend
     pip install -r requirements.txt
     ```
   - Frontend:
     ```bash
     cd frontend
     npm install
     ```
3. **Start the Development Servers:**
   - Backend:
     ```bash
     python app.py
     ```
   - Frontend:
     ```bash
     npm start
     ```
4. **Deploy Smart Contracts:**
   - Use Hardhat/Remix to deploy the smart contracts and update the contract addresses in the frontend and backend configuration files.

---

## Usage
1. **Upload Research Papers:**
   - Researchers can upload their papers to the platform, which are securely stored on IPFS.
2. **Assign Reviewers:**
   - The system selects reviewers based on their expertise and availability.
3. **Submit Reviews:**
   - Reviewers provide feedback and ratings for the assigned papers.
4. **Earn Rewards:**
   - Reviewers receive tokens as incentives for their contributions.
